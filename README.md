## 🔍 Visão Geral

Esta landing page foi construída para destacar produtos, serviços ou marcas de forma marcante. Conta com seções estratégicas projetadas para prender a atenção do visitante, transmitir autoridade e incentivar a chamada para ação (CTA).

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias essenciais de desenvolvimento web frontend, sem dependências de frameworks pesados, garantindo velocidade de carregamento:

- **HTML5:** Estruturação semântica, acessível e otimizada para SEO.
- **CSS3:** Estilização avançada, uso de variáveis customizadas, Flexbox/Grid e arquitetura modular de arquivos.

## 📁 Estrutura de Pastas

A organização do código foi planejada para facilitar a manutenção e a escalabilidade:

```text
.
├── CSS/
│   ├── global.css       # Configurações globais, variáveis de cor, tipografia e reset
│   └── style.css        # Estilos específicos para os componentes da landing page
├── image/
│   ├── Logo_ficticio.jpg               # Logotipo oficial da marca
│   ├── pexels-davegarcia-37240355.jpg  # Imagem de destaque/herói (Hero section)
│   ├── favicon.ico                     # Favicon do site
│   └── icons/                          # Ícones e assets responsivos para dispositivos móveis
├── index.html           # Arquivo principal da aplicação
└── README.md            # Documentação do projeto
```

## ⚙️ Como Executar o Projeto

Para visualizar e testar o projeto em sua máquina local, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. **Abra o projeto:**
   Abra a pasta do projeto em seu editor de código favorito (ex: **VS Code**).

3. **Inicie o servidor local:**
   - A maneira mais prática é utilizando a extensão **Live Server** no VS Code.
   - Basta clicar com o botão direito no arquivo `index.html` e selecionar **"Open with Live Server"**.
   - O projeto abrirá automaticamente no seu navegador padrão.
